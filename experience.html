Day 1 | Order Data Processing & Transaction Aggregation
Project Context

Teratu Spreadsheet Contest · Shopee Order Data · Google Sheets

Business Problem

The raw Shopee order dataset contained 7,028 records across 18 source columns. The challenge required transforming the source data into a completed order summary, standardizing numeric values, calculating order level amounts, and consolidating discount and voucher information without modifying the original database.

Objective

Transform raw Shopee order data into an order level summary of completed transactions using spreadsheet formulas while preserving source data integrity and meeting the contest's expected output requirements.

Processing Workflow

Inspect Source Data → Extract Order Information → Standardize Numeric Values → Calculate Line Level Amounts → Identify Completed Orders → Aggregate Transactions → Retrieve Vouchers → Validate Output

Formula Techniques & Methods

1. Order Data Extraction

  • Direct cell references to retrieve original order numbers and order statuses without modifying the source worksheet.

2. Numeric Data Standardization

  • VALUE + SUBSTITUTE to convert quantities, prices, and discount values stored as text into numeric values.
  • Removed thousands separators before numeric conversion.

3. Line-Level Calculations

  • Multiplication to calculate original price and discounted-price amounts based on quantity.
  • Addition to combine seller funded and Shopee funded voucher values.

4. Completed Order Identification

  • IF + AND + COUNTIF to identify the first occurrence of each completed order.
  • N and addition to generate sequential helper numbers for completed-order identification.

5. Dynamic Array Solution

  • ARRAYFORMULA + LET + UNIQUE + FILTER to identify unique completed orders and prepare dynamic order lists.
  • BYROW + LAMBDA + SUMIFS to calculate order-level subtotals for original prices, discounted prices, and discounts.
  • XLOOKUP to retrieve corresponding voucher values.
  • HSTACK + IF to assemble calculated arrays into the required output structure.

6. Alternative Helper Sequence Solution

  • IFERROR + INDEX + MATCH + ROWS to retrieve completed order numbers through a sequential helper mechanism.
  • IF + SUMIFS to calculate order-level subtotals.
  • INDEX + MATCH to retrieve voucher values.
  • Arithmetic operators to calculate discount and voucher percentages.

Teratu Spreadsheet Contest · Shopee Order Data · Google Sheets

Business Problem

The raw order dataset contained Mini SKU ID values that could combine multiple four digit identifiers into a single field. These identifiers needed to be separated into individual SKU components before quantities could be aggregated accurately for completed orders. For example, the combined value 90499001 represents two Mini SKU IDs: 9049 and 9001.

Objective

Transform combined Mini SKU IDs into individual four digit identifiers, associate each identifier with its original transaction details, and aggregate quantities for completed orders while preserving source data integrity.

Processing Workflow

Extract Transaction Fields → Split Combined SKU IDs → Expand Individual SKU Records → Identify Unique Mini SKU IDs → Aggregate Completed Order Quantities → Validate Output

Formula Techniques & Methods

1. Transaction Data Preparation

  • FILTER + HSTACK to select relevant transaction fields and combine them into a working dataset.

2. Mini SKU Extraction & Expansion

  • MAKEARRAY + LAMBDA + SCAN + MATCH + INDEX + CHOOSE to transform combined SKU values into individual components while retaining associated transaction information.
  • REGEXEXTRACT to extract four digit Mini SKU identifiers from combined values.
  • TOCOL to consolidate extracted identifiers into a single column.
  • ARRAYFORMULA + LET to apply extraction logic across arrays and organize intermediate calculations.

3. Helper Based Quantity Aggregation

  • SORT + UNIQUE + FILTER to generate a sorted list of distinct Mini SKU IDs.
  • SUMPRODUCT + IFERROR + VALUE + TO_TEXT to calculate total quantities associated with each Mini SKU ID using the prepared transaction data.

4. Transaction Reconstruction & Dynamic Processing

  • FILTER + HSTACK to prepare and combine transaction fields.
  • LEN + SCAN + MAKEARRAY + LAMBDA to reconstruct the expanded SKU structure.
  • MAP + SEQUENCE + INDEX + MATCH to associate extracted SKU components with their original order numbers, statuses, and quantities.
  • SORT + UNIQUE + FILTER + SUMPRODUCT to produce the required SKU quantity summary.

The source database contained 236,056 data rows across 18 columns. To analyze average order value (AOV) by province and shipping method, transaction values first needed to be consolidated at the order level. 2. Transaction Value Calculation

  • Multiplication to calculate line level transaction values using discounted price multiplied by quantity.
  • QUERY + GROUP BY + SUM to consolidate line level transaction values by order number, shipping method, and province into order level totals.

3. QUERY Approach

  • QUERY + GROUP BY + SUM to aggregate transaction values at the order level.
  • QUERY + AVG to calculate average order level totals for each province and shipping method combination.
