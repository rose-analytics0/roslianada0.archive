Machine Learning-Based Fraud Detection Research

Machine Learning Based Fraud Detection in Digital Financial Transactions · Undergraduate Thesis

Research Background

My interest in financial data analytics eventually led me to explore machine learning as the subject of my undergraduate thesis.

Although my academic background was in Accounting rather than Computer Science, I chose to combine financial transaction analysis with machine learning to explore a more technology driven approach to fraud detection.

This required independent learning beyond my formal accounting curriculum. I studied machine learning concepts, reviewed relevant research literature, compared methodological approaches, and explored techniques suitable for financial fraud detection.

Based on this learning process, I selected XGBoost as the classification algorithm and incorporated SMOTE (Synthetic Minority Over sampling Technique) to address the imbalance between legitimate and fraudulent transaction classes.

The research involved data preparation, feature engineering, model development, and performance evaluation using approximately 6.36 million synthetic financial transaction records.

Research Objectives

  • Examine transaction characteristics and identify patterns associated with potentially fraudulent activities.
  • Evaluate the limitations of an existing rule based fraud detection indicator.
  • Prepare and transform large scale transaction data for machine learning analysis.
  • Develop an XGBoost classification model to distinguish normal and fraudulent transactions.
  • Address class imbalance using the Synthetic Minority Over sampling Technique (SMOTE).
  • Evaluate model performance through AUC, precision, recall, confusion matrix, and processing time.
  • Assess the potential application of machine learning as an analytical tool to support digital audit procedures.

Dataset Background - PaySim

The research used PaySim, a synthetic mobile money transaction dataset developed by Edgar Alonso Lopez Rojas and collaborators.

PaySim was designed to simulate mobile money transactions using an approach informed by real financial transaction data. Its development addressed a major research limitation: the restricted availability of genuine financial transaction records because of privacy and confidentiality concerns.

The simulator's research foundation was presented at the 28th European Modeling and Simulation Symposium (EMSS) in 2016.

The public dataset was generated using a simulation approach informed by aggregated transaction data from a real mobile money service. It reproduces transaction characteristics and simulated fraudulent behavior while avoiding the direct disclosure of confidential customer transaction records.

This made PaySim a suitable research resource for exploring and evaluating fraud detection methods in a simulated financial environment.

Research Data Disclosure: This study used the PaySim synthetic financial transaction dataset. The data represents simulated mobile money transactions based on observed characteristics of real world financial operations; it does not contain actual customer or company transaction records.

Research Methodology

The research process involved the following stages:

  • Data Understanding & Preparation - examining transaction structures, data characteristics, and variables relevant to fraud detection.
  • Feature Engineering - preparing and transforming relevant transaction attributes for model development.
  • Class Imbalance Handling - applying SMOTE to address the imbalance between legitimate and fraudulent transactions in the training data.
  • Model Development - developing an XGBoost classification model.
  • Model Evaluation - assessing model performance using AUC, recall, precision, and processing time.
